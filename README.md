# Slab 1 — All 4 Beginner Data Analysis Projects

1. `task1_retail/` — interactive Streamlit retail dashboard (`streamlit run app.py`)
2. `task2_student/` — student score analysis and prediction (`python student_performance.py`)
3. `task3_customer/` — RFM customer segmentation with K-Means (`python customer_segmentation.py`)
4. `task4_house/` — house price regression comparison (`python house_price_prediction.py`)

Each folder contains code, requirements, README, and a CSV dataset. Open a task folder in VS Code, create a virtual environment with `py -m venv .venv`, activate it using ` .venv\Scripts\Activate.ps1`, install dependencies with `pip install -r requirements.txt`, and run the command in that task's README.
